About Me

Hi, I’m Jd Selwyn, born on October 31, 2008. I’m a first-year IT student at the University of the Cordilleras, working toward becoming a full stack developer. I like making clean websites, helpful projects, and small tools that do one job well.

I mostly write HTML, CSS, JavaScript, Java and Python. This portfolio is hand-coded, and in Java I built a bitwise calculator that shows a truth table and a small circuit simulator.

I recently joined an AWS Student Builder Group because I want to learn cloud computing from the beginning. I’m still new to it, and I’m enjoying that.

If I had to describe myself in four words, they’d be creative, minimalist, strategic and authentic. I keep my designs simple, think a problem through before I build it, and like my work to look like me.
